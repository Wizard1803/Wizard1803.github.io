# WIZARD — Portfolio

Personal portfolio site for Piyush (Wizard1803), targeting red team / offensive security internships.

## Tech Stack

- Vanilla HTML / CSS / JS — no framework, no build step
- GSAP + ScrollTrigger (CDN) for animation
- Native View Transitions API for cross-page navigation
- Deployed as a static site on GitHub Pages

## Local Development

No install step required. Serve the project root with any static server:

```bash
# Python
python -m http.server

# Or use VS Code "Live Server" extension
```

> **Note:** Opening HTML files directly via `file://` will block `fetch()` calls. Always use a local server.

## Design Reference

The cockpit dashboard hero is inspired by Lamborghini instrument cluster geometry — angular chevrons, spatial hierarchy, dark cinematic lighting. Extracted as mood/structure reference only; no literal automotive branding is used.
